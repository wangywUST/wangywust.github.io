Digital angular frequency: radians per sample

Each move from sample n to sample n+1 advances the phase by exactly ω radians. The highlighted sample and rotating phasor are synchronized.

Meaning: x[n] = cos(ωn). Moving one index forward changes the phase from ωn to ω(n+1), so Δθ = ω.
Conversion: ω = ΩTs = 2πf/fs. Thus ω/(2π) is the fraction of a full cycle completed per sample.
At ω = π/2 rad/sample, the phase advances by 90° each sample, so one cycle takes four samples.
